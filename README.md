# 학생 건강검사 머신러닝 실습 데이터 (student-health-ml-data)

충북대학교 「Python 활용 머신러닝 및 딥러닝 특강」(2026-11) 실습용. Orange3 · Python 어느 쪽에서든 URL로 바로 읽습니다.

## 파일
| 파일 | 줄 | 설명 |
|---|---|---|
| `student_health_3000.csv` | 3,000 | 수업용. 초4 · 중1 · 고1 각 1,000명 |
| `hidden_500_input.csv` | 500 | 4일차 대회 입력. **성별 열이 없음** — 맞혀서 제출 |
| 정답 | — | 수업 뒤 공개 |

Orange **File** 위젯 → URL 칸:
```
https://raw.githubusercontent.com/aicec/student-health-ml-data/main/student_health_3000.csv
```

| 키_cm | 숫자 | cm | |
| 몸무게_kg | 숫자 | kg | |
| 체질량_등급 | 범주 | 저체중 · 정상 · 과체중 · 비만 | 키 · 몸무게로 계산된 등급 |
| 수축기혈압 | 숫자 | mmHg | 회귀 과제 정답(2일차) |
| 이완기혈압 | 숫자 | mmHg | |
| 라면 · 음료수 · 패스트푸드 · 육류 · 우유유제품 · 과일 · 채소 | 범주 | 안 먹음 · 주 1~2번 · 주 3~5번 · 매일 | 일주일 섭취 빈도 |

## 출처 · 이용 조건
- 원본: 교육부 **「학생건강검사 표본조사 rawdata」 2025** — 공공데이터포털 https://www.data.go.kr/data/15100360/fileData.do (이용허락범위 제한 없음). 매년 초4 · 중1 · 고1 등 표본학교 학생건강검사 원시자료(정부 지정통계 112002호).
- 가공: 혈압이 있는 초4 · 중1 · 고1만 남기고, 혈액검사(비만 학생만 측정)와 구강 · 설문 민감 항목은 뺐으며, 코드값을 한글로 풀고 학년군별 1,000명을 무작위 추출했습니다. 개인 식별 정보는 원본에도 없습니다.
- 변환 스크립트: `scripts/convert_health.py`
